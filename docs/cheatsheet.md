# tmux

## windows

- new: `c`, list: `w`, close: `&`
- previous: `p`, next: `n`

## panes

- new below: `"`, new right: `%`
- nav: `←↓↑→`, cycle: `o`
- swap behind: `{`, swap ahead: `}`
- close: `x`

# nvim

- yank line: `yy`, chg word: `cw`, del char: `x`
- newl below: `o`, above: `O`
- top: `gg`, bottom: `G`
- ln start: `0`, end: `$`
- down: `⌃d`, up: `⌃u`
- join next line: `J`
- find: `/…`, previous: `N`, next: `n`
- find replace: `:%s/…/…/g`
- files: ` ff`, grep: ` fg`, open: ` fb`
- diagnostics: buffer ` e`, previous `[d`, next `]d`
- buffers: prev `⇧h`, next `⇧l`, close ` bd`, all ` b⇧d`
- browse: ` -`, project: ` cw`
- windows: `⌃w h/j/k/l`

# yazi

- open file: `↵`, close: `q`
- open right: `⌃v`, below: `⌃x`, tab: `⌃t`
- help: `F1`

# fd

- extension: `-e`, hidden/ignored: `-HI`
- file: `-t f`, dir: `-t d`

# ripgrep

- case-insensitive: `-i`, whole word: `-w`, glob: `-g`
- no preview: `-l`

# flakes

- validate: `nix flake check`
- update input: `nix flake update <input>`, apply: `rebuild`
