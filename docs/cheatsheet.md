# tmux

## windows

- new: `c`, list: `w`, close: `&`
- previous: `p`, next: `n`

## panes

- new below: `"`, new right: `%`
- nav: `arrows`, cycle: `o`
- swap behind: `{`, swap ahead: `}`
- close: `x`

# nvim

- yank line: `yy`, chg word: `cw`, del char: `x`
- newl below: `o`, above: `O`
- top: `gg`, bottom: `G`
- ln start: `0`, end: `$`
- down: `ctrl+d`, up: `ctrl+u`
- join next line: `J`
- find: `/{}`, previous: `N`, next: `n`
- find replace: `:%s/{}/{}/g`
- browse: ` -`
- windows: `ctrl+w`

# yazi

- open file: `↵`, close: `q`
- open right: `ctrl+v`, below: `ctrl+x`, tab: `ctrl+t`
- help: `F1`

# fd

- extension: `-e`, hidden/ignored: `-HI`
- file: `-t f`, dir: `-t d`

# ripgrep

- case-insensitive: `-i`, whole word: `-w`, glob: `-g`
- no preview: `-l`

# flakes

- validate: `nix flake check`
- update input: `nix flake update <input>`, apply: `rebuild`
