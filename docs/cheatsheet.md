# tmux

## windows

- new: `c`, list: `w`, close: `&`
- previous: `p`, next: `n`

## panes

- new below: `"`, new right: `%`
- nav: `arrows`, cycle: `o`
- swap behind: `{`, swap ahead: `}`
- close: `x`

# vim

- yank line: `yy`, chg word: `cw`, del char: `x`
- newl below: `o`, above: `O`
- top: `gg`, bottom: `G`
- ln start: `0`, end: `$`
- join next line: `J`

# fd

- extension: `-e`, hidden/ignored: `-HI`
- file: `-t f`, dir: `-t d`

# ripgrep

- case-insensitive: `-i`, whole word: `-w`, glob: `-g`
- no preview: `-l`
